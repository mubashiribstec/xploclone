# PC Requirements — XploClone

**Date:** 2026-10-30. **Rule:** buy / rent for the tier you are actually
running. A CPU test machine cannot do live calls, and a 6 GB GPU cannot
do production. If a number below says "unmeasured", it is a target or a
vendor claim, not a measurement — measure it on your hardware and record
it in `docs/BENCHMARK.md`.

Run the preflight check first (no install needed):
```bash
python3 scripts/doctor.py          # human report
python3 scripts/doctor.py --json   # machine-readable
./install.sh --check-only          # Docker + GPU checks only
```

## The three tiers

### Tier A — CPU test / dev only (file generation, no live calls)

| Item | Minimum | Recommended |
|---|---|---|
| CPU | 4 cores x86-64 | 8 cores (Nano's vendor claim assumes 8 threads) |
| RAM | 8 GB | 16 GB |
| Disk free | 10 GB | 20 GB (models + images + outputs) |
| OS | Ubuntu 24.04 / Debian 12 / macOS 13+ (Docker) / Windows 11 + WSL 2 | Ubuntu 24.04 |
| Docker | Docker 24+ + Compose v2 | Docker 29.x (see BUILD-LOG) |
| GPU | None | None — CPU mode uses **Chatterbox Nano** |
| Network | Internet for the first model download (~1 GB) | Same |

What works: API starts, login, Generate page, file generation with
Nano (110M, MIT). What does NOT work: live calls, real-time
interaction, Turbo at usable speed, Urdu (gated, no engine yet).
Expected speed: Nano vendor claim is **3× real-time on 8 CPU cores**
(Resemble AI, verified 2026-10-30 — see `docs/OPEN-SOURCE-CLONERS-2026.md`).
On a 2-core VM like this build machine, expect **slower than real-time**
and treat every number as unmeasured until you run
`scripts/cpu_smoke.py` and a real Nano generation on your hardware.
Concurrency: 1 synthesis at a time, by design.

### Tier B — Dev GPU (one voice, testing, short calls)

| Item | Minimum | Recommended |
|---|---|---|
| GPU | NVIDIA, 6 GB VRAM (e.g. GTX 1660 Super) | **RTX 3060 12 GB** (or RTX 4060 Ti 16 GB) |
| CPU / RAM | 4 cores / 16 GB | 8 cores / 32 GB |
| Disk free | 20 GB | 50 GB |
| Driver | NVIDIA driver supporting **CUDA 13.0** (R570+ family) | Same, latest stable |
| Docker | Docker + nvidia-container-toolkit | Same |

What works: Turbo 350M at production quality for files and short
test calls. What does NOT work: F5-TTS comfortably (needs ~12 GB),
STT + LLM + TTS together on the same 6 GB card, more than 1 concurrent
synthesis. The owner's HP Z640 + GTX 1660 Super 6 GB is **Tier B /
dev-only** — it can run one Turbo engine, it cannot run the full
Xplogent speech stack (Whisper + LLM + TTS) at once. See PLAN-v2 D11.

### Tier C — Production (live calls, Xplogent)

| Item | Requirement |
|---|---|
| GPU | **NVIDIA, ≥ 12 GB VRAM, dedicated to TTS only** (RTX 4060 Ti 16 GB, RTX 5070, L4, A10, or cloud equivalent). Do NOT share it with STT/LLM in v1. |
| CPU / RAM | 8 cores / 32 GB |
| Disk free | 50 GB (models ~2–5 GB, images, logs, encrypted reference store) |
| Driver / CUDA | NVIDIA driver for **CUDA 13.0** (cu130 deviation, BUILD-LOG D1). Confirm before buying GPU time — torch 2.14.1 has no cu128 wheel. |
| Network | Stable, low-latency to the phone/SIP host; outbound HTTPS to Hugging Face for the first model download only |
| Backup | Encrypted backup of reference clips, embeddings, config, API-key hashes (Phase 5); tested restore |
| Uptime | Single GPU = single point of failure. Xplogent must fall back to Cartesia / ElevenLabs if the TTS GPU is down (PLAN-v2 §12.7). |

## Model size / VRAM cheat sheet (verified 2026-10-30)

| Model | Size | VRAM (typical) | CPU? |
|---|---|---|---|
| Chatterbox Nano 110M* | ~0.5 GB weights | Minimal (edge) | **Yes — 3× real-time, 8 threads (vendor)** |
| Chatterbox Turbo 350M | ~1–2 GB | 4–6 GB | Runs, not real-time |
| Chatterbox Multilingual V3 0.5B | ~2 GB | ~8 GB | No |
| Qwen3-TTS 0.6B / 1.7B | 0.6B / 1.7B | ~3.5–4 GB / ~3.9 GB | Slow (file-gen only) |
| F5-TTS ~336M | ~1–2 GB | 2–6 GB (guides vary) | Slow (~2.5× real-time on M5) |
| XTTS v2 ~1.5B | 1.88 GB FP32 | 3–4 GB | ~10× slower than GPU |

\* Nano "110M" is Resemble's figure; an independent survey reconciled
~217M for the T3 backbone. The CPU speed claim is unaffected.
Full table + sources: `docs/OPEN-SOURCE-CLONERS-2026.md`.

## Checklist (copy before you buy / rent)

- [ ] `python3 scripts/doctor.py` — ready for the tier you want?
- [ ] GPU driver supports CUDA 13.0 (Tier B/C) — `nvidia-smi` shows driver version
- [ ] nvidia-container-toolkit installed (Docker GPU mode)
- [ ] 10 GB (CPU) / 20 GB (GPU dev) / 50 GB (prod) disk free
- [ ] Reference clips recorded (60 s proxy first, then 20 min per variant)
- [ ] `.env` secrets generated by `./install.sh` (never a shipped key)
- [ ] Web UI behind localhost/VPN or a reverse proxy with TLS — never public as-is
- [ ] Fallback voice provider configured in Xplogent (GPU-down case)
